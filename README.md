# BuildFlow

A CI/CD pipeline dashboard built with React and Vite, configured for Cursor Cloud Agents.

## Local Development

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Cloud Deployment

This project includes `.cursor/environment.json` for Cursor Cloud Agents. The dev server runs on port 5173 and is exposed for online testing.

## Scripts

- `npm run dev` — Start development server
- `npm run build` — Production build
- `npm run preview` — Preview production build
- `npm run lint` — Run linter
